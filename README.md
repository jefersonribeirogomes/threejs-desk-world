# 🚒 //Fire Engine// Desk World — Three.js Interactive Setup

Um mundo 3D interativo construído em **Three.js** inspirado no estilo isométrico de Bruno Simon, onde o cenário jogável é uma mesa de desenvolvedor real expandida e o veículo controlável é o caminhãozinho de bombeiro **`//Fire Engine//`**.

## 🎮 Controles

- **`W A S D` ou `Setas`:** Dirigir o caminhãozinho pela mesa (e subir nas teclas do teclado mecânico)
- **`Espaço`:** Apertar o botão amarelo no teto e disparar o jato de água
- **`Scroll do Mouse`:** Zoom In / Zoom Out
- **Botões de Câmera:** Alternar entre *Visão Mesa*, *Close no Carrinho* e *Visão Geral Setup*

## 🚀 Como rodar localmente

Basta servir a pasta com qualquer servidor HTTP estático:

```bash
npx http-server . -p 8085
# ou
python -m http.server 8085
```
